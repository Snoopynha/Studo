> Aplicativo mobile de gerenciamento gameficado de tarefas do Google Classroom.

## Funcionalidades  
- **Integração com o Google Classroom** onde logo ao acessar o app com o email é puxado as informações das salas e tarefas vinculadas a sua conta do Google.
- **Filtagem de tarefas** por status e por prazo. 
- **Medalhas e níveis por conta** ganhados conforme as tarefas são entregues.
- **Calendário** com visualização das tarefas do mês e do dia.

## Tecnologias
### Aplicativo (Mobile)
- [React Native](https://reactnative.dev) - Framework mobile.
- [Expo](https://expo.dev/) - Ambiente de desenvolvimento.
- [TypeScript](https://typescriptlang.org) - Linguagem de programação

### Backend e serviços
- [Node.js](https://nodejs.org/pt-br) - Servidor do projeto
- [Google Classroom API](https://developers.google.com/workspace/classroom?hl=pt-br) - Integração com as turmas e tarefas.

## Como rodar o projeto localmente
1. Clonar o projeto

~~~bash  
  git clone https://github.com/Snoopynha/Stellar-Legacy.git

  # Acesse a pasta do projeto
  cd stellar-legacy
~~~

2. Instalar as dependências 

~~~bash  
  npm install
~~~

3. Iniciar o projeto (Expo)

~~~bash  
  npm run start
~~~  

4. Visualizar o aplicativo

Após iniciar o servidor, você pode testar o projeto de duas formas:

* **Pelo celular (QR Code):** Abra o aplicativo **Expo Go** no seu smartphone e escaneie o QR Code exibido no terminal.
* **Pelo navegador:** Pressione a tecla **`w`** diretamente no seu terminal para abrir a versão web do aplicativo.
